# Evidence folder

- `run_summary.txt` is produced by `src/run_all.py` and records every experiment.
- `prompt_record.md` records the prompts used for each experiment.
- `experiment_results.png` is a generated image of the verified run transcript.
- `prompt_record.png` is a generated image of the prompt record.

The PNG files are evidence captures generated from repository text. If the
instructor specifically requires screenshots of the chat interface, take those
screenshots manually and add them here before submission; do not include names,
email addresses, API keys, or unrelated conversations.
